### Method A: Using Git Terminal (Fastest)

We have already created the complete repository folder ready for you at `d:\Git-Interior\mohammadasim07`.

1. Go to [GitHub New Repository](https://github.com/new).
2. Set **Repository name** to: `mohammadasim07` (GitHub will display a green banner saying *"You found a secret!"*).
3. Ensure it is set to **Public**.
4. Check **Add a README file** (or leave unchecked).
5. Click **Create repository**.
6. Open your terminal in PowerShell and run:

```powershell
cd d:\Git-Interior\mohammadasim07
git init
git add .
git commit -m "feat: initial professional profile readme and assets"
git branch -M main
git remote add origin https://github.com/mohammadasim07/mohammadasim07.git
git push -u origin main --force
```

*(If you already created the repo via web, git push will immediately update it with your custom banner and layout).*
